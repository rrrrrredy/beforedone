## Explicit evidence boundary

This host executed the Windows amd64 archive natively. It did not execute the
macOS, Linux, or Windows arm64 archives natively; cross-compilation, embedded
module metadata, archive contents, checksums, and SBOM inspection are not
presented as native-runtime proof for those targets.

Built-in redaction remains best effort. It reduces accidental persistence of
common credential forms but does not prove that every provider, encoding,
sensitive filename, argv value, or private path has been removed. Users must
still review artifacts before sharing them.

The canceled OpenAI Directory distribution is not part of v1.0.2 and no
Directory artifact is published with this release.
